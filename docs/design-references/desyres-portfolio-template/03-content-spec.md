# Especificación de contenido — Webs Inteligentes

## Promesa

QuantumHive convierte la presencia digital de un negocio en una experiencia
profesional que presenta, explica, guía y queda preparada para atender todo el
día. No se prometen cifras, porcentajes ni resultados no comprobados.

## Mensajes obligatorios

- `TU NEGOCIO 24/7`
- `AUTOMATIZADO. CONECTADO. INTELIGENTE.`
- El problema: una web común muestra información pero no acompaña al cliente.
- La solución: catálogo, demo personalizada, efectos/remix y agente integrado.
- El cliente mantiene el control y aprueba cada etapa.

## Flujo del servicio

1. Explorar el catálogo.
2. Elegir una base.
3. Cargar la información real del negocio.
4. Revisar la demo.
5. Personalizar efectos y pedir remixes.
6. Integrar el agente creado en la Fábrica de Agentes.

## Restricciones

- No inventar testimonios, clientes, métricas ni integraciones.
- No atribuir demos a negocios reales.
- La capa conversacional se presenta como una integración posterior a la
  aprobación del diseño y la información.
- Debe verse `Powered by Quantum Hive` en el pie.
