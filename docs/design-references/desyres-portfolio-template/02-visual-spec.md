# Especificación visual — QuantumHive

## Identidad

- Fondo negro carbón.
- Dorado metálico como acento dominante.
- Colmena y hexágonos como lenguaje gráfico.
- Cian o violeta únicamente como brillo secundario de energía cuántica.
- Sin verde lima.
- Titulares fuertes, geométricos y limpios; cuerpo sobrio y legible.

## Portada

El concepto principal es `TU NEGOCIO 24/7`, acompañado por la secuencia
`AUTOMATIZADO / CONECTADO / INTELIGENTE`. La imagen principal debe provenir de
la biblioteca entregada por el usuario y comunicar tecnología profesional, no
una estética genérica de IA.

## Imágenes seleccionadas

La adaptación puede usar únicamente los archivos normalizados de
`public/templates/desyres-quantum/brand/`. Se priorizan `quantum-presence.jpeg`,
`organic-honeycomb.jpeg`, `agent-builder.jpeg`, `agents-dashboard.jpeg`,
`agi-fusion.jpeg` y `neural-pathways.jpeg`.

## Efectos

Se conservan Webflow IX, GSAP, SplitText y ScrollTrigger originales. Los cambios
de color se hacen con una hoja de overrides cargada después del CSS fuente.
No se modifica `overflow` de ancestros de elementos sticky; usar
`overflow-x: clip` cuando sea necesario.
