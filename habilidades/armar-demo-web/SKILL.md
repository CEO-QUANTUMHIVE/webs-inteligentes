# Armar Demo Web (Quantum Hive Web Factory)

Esta skill de Antigravity automatiza el proceso de ensamblar una página web premium.

## Instrucciones para el Agente:
1. Lee el brief del cliente desde la carpeta documentacion/.
2. Copia la plantilla base de plantillas/base-premium hacia clientes/[nombre-cliente].
3. Aplica los estilos del sistema-de-diseno basándose en el rubro del cliente.
4. Reemplaza el texto dummy con la información real extraída del brief.
5. Ejecuta 
pm run build para validar.
