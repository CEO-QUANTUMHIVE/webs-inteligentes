# Prompt: Mejorar Web Existente

MODO MEJORA PREMIUM.

Antes de tocar nada, auditá la web actual:

- ¿qué se siente genérico?
- ¿dónde falla la jerarquía visual?
- ¿qué animaciones sobran o faltan?
- ¿cómo está el performance?
- ¿cumple accesibilidad básica?

Después consultá:

- `habilidades/web-premium/patrones/`;
- `frontend-design`;
- `ui-ux-pro-max`;
- `web-animation-design`;
- `seo-audit` si aplica.

Aplicá cambios mínimos de alto impacto:

- mejorar tipografía y espaciado;
- eliminar elementos decorativos innecesarios;
- agregar 1-2 momentos de motion con propósito;
- optimizar assets y LCP;
- corregir contrastes y focus states.

No rehacer toda la web salvo que sea necesario. Mejorá lo que existe.
