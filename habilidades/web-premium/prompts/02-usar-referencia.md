# Prompt: Usar Referencia

MODO REFERENCIA PREMIUM.

La URL suministrada NO debe copiarse literalmente.

Estudiala como referencia visual.

Identificá:

- composición;
- jerarquía;
- layout;
- motion;
- scroll;

- interacción;
- técnicas interesantes.
