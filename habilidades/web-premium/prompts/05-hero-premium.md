# Prompt: Hero Premium

MODO HERO PREMIUM.

El hero es la primera impresión. Debe ser memorable en 3 segundos.

Pasos:

1. Elegí un patrón de hero acorde al negocio:
   - producto central inmersivo;
   - video/textura atmosférica;
   - tipografía monumental;
   - composición asimétrica con CTA claro.

2. Definí la jerarquía:
   - 1 elemento principal (imagen, producto o frase);
   - 1 CTA primario;
   - 0 distracciones secundarias.

3. Motion de entrada:
   - stagger controlado;
   - no más de 3 elementos animando simultáneamente;
   - easing natural.

4. Performance:
   - hero visible en < 1.5s;
   - LCP crítico optimizado;
   - nada de WebGL pesado sin fallback estático.

5. Mobile:
   - el mensaje principal debe leerse sin scroll;
   - reducir elementos decorativos.
