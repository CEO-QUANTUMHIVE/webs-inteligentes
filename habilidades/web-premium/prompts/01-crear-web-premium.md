# Prompt: Crear Web Premium

MODO DISEÑO PREMIUM.

Antes de diseñar, estudiá los datos del negocio.

Después consultá:

- biblioteca de patrones premium (`habilidades/web-premium/patrones/`);
- referencias relevantes (`habilidades/web-premium/referencias/`);
- `frontend-design`;
- `ui-ux-pro-max`;
- componentes disponibles (`21st-cli-use`);
- motion disponible (`web-animation-design`, GSAP skills);
- catálogo 3D (`web-3d`) si aporta valor.

No construyas una landing genérica.

Definí una dirección visual clara.

Elegí sólo los patrones que tengan sentido para este negocio.

Remixealos.

No copies literalmente una referencia.

Objetivo: una web original, memorable, visualmente fuerte, fluida y rápida.
