# Prompt: Remix de Referencias

MODO REMIX PREMIUM.

Usá varios patrones existentes de la biblioteca.

No reproduzcas una sola web.

Combiná por ejemplo:

- hero de referencia A
- scroll de referencia B
- navigation de referencia C
- cards de referencia D
- motion propio

El resultado debe sentirse coherente, no como piezas pegadas.

Una sola dirección artística.
