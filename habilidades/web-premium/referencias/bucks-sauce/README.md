# Referencia: Bucks Sauce

URL estudiada: https://buckssauce.com/

## Propósito del estudio

Aprender cómo una landing de producto único puede usar el producto como héroe central, storytelling por scroll y elementos flotantes sin caer en la genéricidad.

## Qué NO se reutiliza

- Logo, nombre y branding de Bucks Sauce.
- Textos, slogans y copy originales.
- Imágenes de producto, botellas y assets fotográficos.

## Qué SÍ se aprende

- Composición centrada en el producto.
- Narrativa de scroll por escenas.
- Interacción mouse/producto.
- Uso de color de fondo cálido y acentos vibrantes.
- Escala tipográfica y jerarquía.
