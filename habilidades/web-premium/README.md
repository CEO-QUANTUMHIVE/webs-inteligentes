# Biblioteca Web Premium

Repositorio de patrones visuales, técnicos y de interacción aprendidos de webs premium, awards y estudios creativos.

## Propósito

- Acumular vocabulario visual propio de QuantumHive.
- Aprender de referencias sin copiarlas literalmente.
- Remixar patrones para crear webs originales.
- Alimentar el orquestador `recrear-web-premium`.

## Estructura

```
habilidades/web-premium/
├── patrones/           # Patrones reutilizables por categoría
├── referencias/        # Análisis de webs estudiadas
└── prompts/            # Prompts base para tareas comunes
```

## Cómo usar

1. Antes de diseñar una web premium, consultá `patrones/` por categoría.
2. Si hay una referencia estudiada, leé `referencias/<nombre>/`.
3. Seleccioná solo los patrones que tengan sentido para el negocio.
4. Remixalos en una dirección visual coherente.

## Reglas

- NO guardar copias completas de webs externas.
- NO guardar logos, textos, branding ni imágenes propietarias.
- SÍ documentar composición, movimiento, jerarquía, timing e interacción.
- Cada patrón debe tener: qué hace, cuándo usarlo, técnica, performance y mobile fallback.
