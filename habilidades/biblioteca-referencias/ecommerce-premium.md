# Ecommerce Premium - Biblioteca de Referencias

## Propósito
URLs de referencia para copiar tiendas online premium con catálogos, carrito y checkout.

## Referencias Seleccionadas

### 1. Apple Store
- **URL**: https://apple.com/shop
- **Por qué**: Catálogo minimalista con grids elegantes
- **Elementos a copiar**:
  - Grid de productos limpio
  - Hover effects sutiles
  - Filtros laterales
  - Quick view
  - Carrito deslizante
- **Paleta sugerida**: Blanco/negro minimalista

### 2. Shopify Dawn Theme
- **URL**: https://dawn.shopify.com
- **Por qué**: Theme gratuito de Shopify, muy bien diseñado
- **Elementos a copiar**:
  - Hero con slideshow
  - Featured products grid
  - Collection list
  - Newsletter signup
  - Footer completo
- **Paleta sugerida**: Personalizable

### 3. Gymshark
- **URL**: https://gymshark.com
- **Por qué**: Ecommerce de indumentaria con filtros avanzados
- **Elementos a copiar**:
  - Mega menu
  - Filtros de productos
  - Quick add to cart
  - Size guide modal
  - Reviews integration
- **Paleta sugerida**: Negro/neón

### 4. Allbirds
- **URL**: https://allbirds.com
- **Por qué**: Ecommerce sostenible con storytelling
- **Elementos a copiar**:
  - Product storytelling
  - Sustainability badges
  - Size finder
  - Reviews with photos
  - Subscription option
- **Paleta sugerida**: Verde/natural

### 5. Glossier
- **URL**: https://glossier.com
- **Por qué**: Ecommerce de belleza con UGC
- **Elementos a copiar**:
  - User generated content
  - Reviews with photos
  - Bundle builder
  - Quiz personalizado
  - Instagram feed
- **Paleta sugerida**: Rosa/blanco

### 6. MVMT
- **URL**: https://mvmt.com
- **Por qué**: Ecommerce de relojes con lifestyle
- **Elementos a copiar**:
  - Lifestyle imagery
  - Product configurator
  - Urgency badges
  - Free shipping bar
  - Recently viewed
- **Paleta sugerida**: Negro/dorado

### 7. Warby Parker
- **URL**: https://warbyparker.com
- **Por qué**: Ecommerce de lentes con try-on virtual
- **Elementos a copiar**:
  - Virtual try-on
  - Home try-on program
  - Quiz de estilo
  - Store locator
  - Insurance info
- **Paleta sugerida**: Azul/clásico

### 8. Bonobos
- **URL**: https://bonobos.com
- **Por qué**: Ecommerce de indumentaria con guía de tallas
- **Elementos a copiar**:
  - Fit guide
  - Style guide
  - Outfit builder
  - Registry
  - alterations service
- **Paleta sugerida**: Azul marino/celeste

## Estructura Estándar Ecommerce

```
1. Header
   - Logo
   - Navigation (mega menu)
   - Search bar
   - Cart icon
   - Account

2. Hero
   - Slideshow o video
   - Featured collection

3. Featured Products
   - Grid 4 columnas
   - Quick view
   - Quick add

4. Collections
   - Grid de categorías
   - Hover effects

5. Product Page
   - Gallery
   - Info
   - Add to cart
   - Reviews
   - Related products

6. Cart
   - Slide-out cart
   - Upsell
   - Checkout CTA

7. Footer
   - Links
   - Newsletter
   - Social
   - Trust badges
```
