# Hero Impactantes - Biblioteca de Referencias

## Propósito
URLs de referencia para copiar hero sections impactantes con animaciones y efectos visuales premium.

## Referencias Seleccionadas

### 1. Stripe.com
- **URL**: https://stripe.com
- **Por qué**: Hero limpio con gradientes animados, tipografía bold, CTA prominente
- **Elementos a copiar**:
  - Gradiente de fondo animado
  - Tipografía grande y legible
  - Botón CTA con hover effect
  - Layout centrado y minimalista
- **Paleta sugerida**: Azul profesional (#635bff)

### 2. Vercel.com
- **URL**: https://vercel.com
- **Por qué**: Hero oscuro con textos que aparecen, efecto de profundidad
- **Elementos a copiar**:
  - Fondo oscuro con sutiles gradients
  - Texto que aparece con fade-in
  - Grid de features debajo del hero
  - Logo animation
- **Paleta sugerida**: Negro/blanco con acentos

### 3. Linear.app
- **URL**: https://linear.app
- **Por qué**: Hero con animación de producto, tipografía elegante
- **Elementos a copiar**:
  - Mockup del producto animado
  - Tipografía serif elegante
  - Espaciado generoso
  - Micro-interacciones
- **Paleta sugerida**: Púrpura oscuro (#5e6ad2)

### 4. Notion.so
- **URL**: https://notion.so
- **Por qué**: Hero simple con demo interactiva
- **Elementos a copiar**:
  - Demo del producto embebida
  - Copy claro y directo
  - Botones de acción múltiple
  - Social proof (logos de empresas)
- **Paleta sugerida**: Blanco/negro minimalista

### 5. Figma.com
- **URL**: https://figma.com
- **Por qué**: Hero con collages animados, colores vibrantes
- **Elementos a copiar**:
  - Collage de elementos flotantes
  - Colores vibrantes y gradients
  - Animación sutil de elementos
  - CTA con urgencia
- **Paleta sugerida**: Multicolor vibrante

### 6. Loom.com
- **URL**: https://loom.com
- **Por qué**: Hero con video embebido, layout dividido
- **Elementos a copiar**:
  - Video/demo embebida
  - Layout 50/50 (texto + demo)
  - Badge de "nuevo" o "actualizado"
  - Testimonio rápido
- **Paleta sugerida**: Púrpura moderno (#625df5)

### 7. Cal.com
- **URL**: https://cal.com
- **Por qué**: Hero limpio con calendario interactivo
- **Elementos a copiar**:
  - Widget de calendario embebido
  - Copy de valor claro
  - Botón de acción primaria
  - Social proof
- **Paleta sugerida**: Negro/dorado

### 8. Resend.com
- **URL**: https://resend.com
- **Por qué**: Hero minimalista con tipografía elegante
- **Elementos a copiar**:
  - Tipografía serif grande
  - Espaciado extremo
  - Animación sutil de texto
  - Código de ejemplo
- **Paleta sugerida**: Negro/blanco
