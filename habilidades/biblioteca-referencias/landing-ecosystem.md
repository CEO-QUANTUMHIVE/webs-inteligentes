# Landing Ecosystem - Biblioteca de Referencias

## Propósito
URLs de referencia para copiar landing pages completas con múltiples secciones y ecosistema de contenido.

## Referencias Seleccionadas

## Estructura Estándar de Landing

```
1. Hero Section
   - Título + subtítulo
   - CTA primario
   - Demo/screenshot

2. Social Proof
   - Logos de clientes
   - Métricas

3. Features
   - Grid de 3-4 features
   - Iconos + descripciones

4. Cómo Funciona
   - 3 pasos
   - Screenshots

5. Testimonios
   - 2-3 testimonios
   - Fotos + nombres

6. Pricing
   - 2-3 planes
   - Feature comparison

7. FAQ
   - Preguntas frecuentes
   - Accordion

8. CTA Final
   - Último llamado a acción
   - Formulario
```
