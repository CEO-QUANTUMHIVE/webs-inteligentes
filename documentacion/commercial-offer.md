# Web Factory - Oferta Comercial

## Modelo de Negocio

Web Factory opera como un pipeline interno de QuantumHive para generar clientes para Webs Inteligentes y Empleados Virtuales.

## Productos Disponibles

### 1. Web Inteligente Básica
**Incluye**:
- Diseño premium responsive
- Contenido personalizado
- SEO básico
- Agente conversacional textual
- Hosting incluido (1 año)
- SSL incluido

**Precio**: USD 150-300 (implementación) + USD 20-40/mes

### 2. Web Inteligente Pro
**Incluye**:
- Todo lo del plan Básico
- Agente conversacional avanzado
- Integración con WhatsApp (futuro)
- Panel de métricas básico
- Soporte prioritario

**Precio**: USD 300-500 (implementación) + USD 40-80/mes

### 3. Empleado Virtual
**Incluye**:
- Agente con avatar
- Voz sintetizada
- Memoria de conversaciones
- Integración multicanal
- Panel administrativo
- Soporte dedicado

**Precio**: USD 500-1000 (implementación) + USD 80-150/mes

## Programa Piloto Fundador

### Beneficios para el Cliente
- Implementación gratuita o con descuento significativo
- Soporte prioritario durante 3 meses
- Actualizaciones incluidas
- Aparición en portafolio de QuantumHive

### Condiciones
- Permiso para mostrar el proyecto en portafolio
- Dos reuniones de feedback
- Entrega de información dentro de plazos definidos
- Testimonio si queda conforme
- Autorización para publicar capturas y resultados
- Dominio y servicios externos pagados por el negocio
- Alcance limitado y documentado
- Mantenimiento posterior pago

### Valor vs. Precio
```
Valor Real: USD 500-1000
Programa Piloto: USD 0-150
Ahorro: 70-100%
```

## Estructura de Costos (Referencia)

### Por Cliente (Web Inteligente)
- Hosting: USD 5-10/mes
- Dominio: USD 12-15/año
- Agente (tokens): USD 5-15/mes
- Total: USD 15-25/mes por cliente

### Margen Estimado
- Implementación: 80-90% margen
- Suscripción: 60-75% margen
- Escalabilidad: Alta (mismo código, múltiples clientes)

## Comparativa con Agencias Tradicionales

| Concepto | Agencia Tradicional | Web Factory |
|----------|---------------------|-------------|
| Tiempo de entrega | 2-4 semanas | 48-72 horas |
| Precio promedio | USD 1000-3000 | USD 150-500 |
| Incluye agente IA | No | Sí |
| Soporte continuo | Adicional | Incluido |
| Personalización | Alta | Media-Alta |

## Argumentos de Venta

1. **Velocidad**: Tu web lista en 48 horas, no en semanas
2. **Precio**: 70-80% más económico que agencias tradicionales
3. **Tecnología**: Incluye asistente inteligente que atiende 24/7
4. **Resultados**: Convierte visitantes en clientes automáticamente
5. **Sin sorpresas**: Precio fijo, sin costos ocultos

## Scripts de Venta

### Para Negocios sin Web
"¿Cuántos clientes potenciales perdiste el último mes porque no encontraron tu negocio en internet? Podemos tener tu web profesional con un asistente que atienda consultas 24/7 en menos de 48 horas."

### Para Negocios con Web Deficiente
"Tu web actual no está convirtiendo visitantes en clientes. La nueva versión incluye un agente inteligente que responde preguntas, recomienda servicios y captura leads automáticamente."

### Para Prospectos Fríos
"Estuve revisando tu negocio y noté que podrías mejorar tu presencia online. Preparé una demo personalizada para que veas cómo quedaría. ¿Te gustaría verla?"
