# Web Factory - Programa Piloto Fundadores

## Objetivo

Validar el pipeline de Web Factory con clientes reales antes de escalar. El programa piloto busca:

1. Probar la velocidad de generación de demos
2. Medir la calidad del agente conversacional
3. Verificar si alguien paga por el resultado
4. Documentar learnings para escalar

## Clientes Piloto (6 casos iniciales)

### 1. QuantumHive (Prioridad 1)
**Tipo**: Web corporativa + agente diagnóstico
**Objetivo**: Primera demostración funcional de Web Factory
**Estado**: En desarrollo

### 2. Negocio con Tiendanube (Prioridad 2)
**Tipo**: Mejora visual + asesor de productos
**Objetivo**: Validar modelo e-commerce
**Estado**: Propuesta enviada

### 3. Antigua Clienta del Bot (Prioridad 3)
**Tipo**: Web + agente diagnóstico conversacional
**Objetivo**: Recuperar contacto perdido
**Estado**: Pendiente contacto

### 4. Indumentaria de Trabajo (Prioridad 4)
**Tipo**: Catálogo + recomendador por oficio
**Objetivo**: Validar modelo catálogo
**Estado**: Contacto identificado

### 5. Barbería (Prioridad 5)
**Tipo**: Servicios + precios + turnos
**Objetivo**: Validar modelo servicios con turnos
**Estado**: Contacto identificado

### 6. Profesora de Yoga (Prioridad 6)
**Tipo**: Marca personal + clases + captación
**Objetivo**: Validar modelo marca personal
**Estado**: Contacto identificado

## Cronograma

### Semana 1-2: Preparación
- [ ] Completar web de QuantumHive
- [ ] Definir plantilla maestra
- [ ] Establecer proceso de QA
- [ ] Crear materiales de venta

### Semana 3-4: Pilotos Iniciales
- [ ] Construir demo para Tiendanube
- [ ] Contactar a antigua clienta
- [ ] Construir demo para barbería
- [ ] Documentar learnings

### Semana 5-6: Validación
- [ ] Medir respuestas de prospectos
- [ ] Calcular costo por demo
- [ ] Evaluar tasa de conversión
- [ ] Decidir si escalar

## Condiciones del Programa

### Para QuantumHive (Cliente Interno)
- Web completa con agente diagnóstico
- Sin costo (es el primer producto)
- Feedback detallado requerido

### Para Pilotos Externos
- Implementación gratuita o simbólica (USD 50-150)
- Hosting cubierto por QuantumHive (3 meses)
- Dominio pagado por el cliente
- Compromiso de feedback
- Permiso para portafolio
- Soporte prioritario

## Métricas a Medir

### Por Cliente
- Tiempo de generación de demo
- Calidad de la demo (escala 1-10)
- Funcionamiento del agente
- Respuesta del prospecto
- Decisión tomada (rechazo/reunión/compra)

### Generales
- Total de demos generadas
- Tiempo promedio por demo
- Costo promedio por demo
- Tasa de respuesta
- Tasa de conversión a reunión
- Tasa de cierre
- Ingreso total generado

## Learnings Esperados

1. ¿Cuánto tiempo toma realmente generar una demo?
2. ¿Qué plantilla funciona mejor para cada nicho?
3. ¿El agente conversacional agrega valor real?
4. ¿Qué precio está dispuesto a pagar el mercado?
5. ¿Qué tipo de negocio responde mejor?
6. ¿Cuál es el flujo de venta más efectivo?

## Decisiones Posteriores

Basado en los resultados del piloto:

### Si hay éxito (3+ clientes pagando)
- Escalar a 20+ prospectos por semana
- Crear múltiples plantillas
- Automatizar QA
- Contratar helpdesk

### Si hay resultado mixto (1-2 clientes)
- Iterar en el proceso
- Ajustar precios
- Mejorar calidad de demos
- Probar otros nichos

### Si no hay éxito (0 clientes)
- Revisar propuesta de valor
- Cambiar nicho o enfoque
- Reducir costos
- Pivotar el producto
