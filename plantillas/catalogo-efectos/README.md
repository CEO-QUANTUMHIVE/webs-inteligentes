# Catálogo de Efectos - Webs Inteligentes

## Descripción
Página catálogo visual donde los clientes pueden ver y elegir los efectos disponibles para su web. Sin código, solo experiencia visual interactiva.

## Estructura

```
1. Hero Section
   - Título: "Webs Inteligentes"
   - Subtítulo: "Elegí los efectos para tu web"
   - CTA: "Solicitar Presupuesto"

2. Catálogo de Efectos
   - Grid de tarjetas con preview en vivo
   - Filtros por categoría
   - Información de cada efecto

3. Cómo Funciona
   - Paso 1: Elegí tus efectos
   - Paso 2: Nosotros construimos
   - Paso 3: Tu web lista

4. Precios
   - Paquete Básico
   - Paquete Premium
   - Paquete Elite

5. Contacto
   - Formulario para solicitar presupuesto
   - Lista de efectos seleccionados
```

## Efectos a Mostrar

### Fondos
- Rayos Animados (Aurora multicolor)
- Partículas Interactivas (Reaccionan al cursor)

### Texto
- Texto Morfológico (Cambia entre palabras)
- Texto Flip Fade (Flip y fade)
- Texto Escalonado (Aparición por caracteres)

### Tarjetas
- Tarjeta Borde Brillante (Hover con brillo)
- Tarjeta con Cursor (Reacciona al mouse)

### Navegación
- Navbar Spotlight (Sigue al cursor)
- Dock de Vidrio (Para móvil)

### Botones
- Botón Brillo Radial (Brillo al hover)
- Botón Animado (Animaciones de entrada)

### Secciones
- Grid Bento (Para servicios)
- Revelado por Scroll (Aparece al scroll)

## Categorías de Filtros

1. **Todos** - Ver todo
2. **Fondos** - Efectos de fondo
3. **Texto** - Animaciones de texto
4. **Tarjetas** - Componentes de tarjetas
5. **Navegación** - Menús y docks
6. **Botones** - CTAs y botones
7. **Secciones** - Layouts y grids

## Información por Efecto

Cada tarjeta del catálogo mostrará:
- Preview visual en vivo
- Nombre del efecto
- Descripción corta
- Categoría
- Nivel de impacto (1-5 estrellas)
- Ideal para (tipo de negocio)

## Funcionalidad

### Filtros
- Click en categoría para filtrar
- Animación de transición entre filtros
- Contador de efectos mostrados

### Selección
- Click en "Seleccionar" para agregar
- Lista de efectos seleccionados visible
- Total de efectos elegidos

### Carrito de Efectos
- Panel lateral con efectos seleccionados
- Botón "Solicitar Presupuesto"
- Envío de selección por formulario
