## CÓMO APLICAR

1. Definir el nicho del cliente
2. Copiar la paleta correspondiente
3. Pegar en `globals.css` como variables CSS
4. Usar en toda la web para consistencia

```css
@theme inline {
  --color-primary: #FF6B35;
  --color-secondary: #004E89;
  --color-accent: #F7C948;
  --color-bg: #1A1A2E;
  --color-text: #EAEAEA;
}
```
