# providers

## Qué contendrá
Contendrá adaptadores para fuentes externas como catálogos o colecciones.

## Qué no contendrá
No incluirá implementaciones en esta épica inicial, ni código funcional no relacionado a su dominio estricto.

## Relación con el Artifact Bus
Interactuará con el Artifact Bus publicando o consumiendo los artefactos definidos en sus respectivos contratos, manteniendo el principio de comunicación asíncrona basada en documentos.
